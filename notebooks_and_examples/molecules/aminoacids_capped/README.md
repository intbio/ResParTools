# ACE–аминокислота–NME reference set

PDB-шаблоны для сопоставления канонической части модифицированных остатков. Центральный
остаток имеет номер 2, кэпы ACE и NME — 1 и 3. Порядок атомов центрального остатка повторяет
порядок соответствующей записи `aminoacids.rtp`; связи и формальные заряды записаны в PDB.

Источник рабочих копий и независимые сверки: локальная библиотека
`work/capped_library_2026-10-22/` (сборка по `pdb2gmx`, сверка графов с AmberTools/CCD).
Все 29 PDB проверены чтением `pt.pdb_to_chem`, который не добавляет proximity bonds при наличии
`CONECT`. В набор входят протонированные варианты ASP/GLU/HIS/CYS/LYS и нестандартные DAB/ORN/HYP.
