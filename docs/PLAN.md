## Решения (кратко)
- Старые ноутбуки не редактируются; несовместимые старые вызовы - предупреждение, не ошибка.
- Родительский остаток указывается явно; без молчаливых подмен (функция сообщает).
- RESP по умолчанию: ACE-X-NME, φ/ψ заморожены (`fix_backbone=True`, флаг отключает или задаёт свои
  пары), 2 × 3 конформации, HF/6-31G*, MSK, двухстадийный RESP, равные веса; оптимизатор geomeTRIC.
- Два окружения (`darwin_ec`, `darwin_resp`), ноутбук остаётся в `darwin_ec`.
- Тип CE ацилированных лизинов остаётся `C8`. Типы acpype у новых атомов не меняются; параметры - из
  `ffbonded.itp`, если сочетание типов там есть, иначе из acpype.
- rtp меток (`CY3_*`, `CY5_*`, `Cy3_syn.rtp`) - в `notebooks_and_examples/dyes_wip/` до решения по
  типам GAFF.
- Раскладка результатов: SDF и `*_rn_H_3D.pdb` → `<папка>/molecules/`, JSON → `<папка>/data/` (в git),
  задачи RESP → `RESP_data/`, acpype → `Acpype_data/`, GROMACS/МД → `build/`. Совсем старые ноутбуки →
  `<папка>/archive/`; компактные `*_old` в каждой папке; новые `1_residue_charges`, `2_forcefield`.
- Git: работа в рабочей ветке `feature/…`, в `main` - целиком после тестов (`main` на кластере всегда
  рабочий); сразу в `main` - только срочное исправление для кластера, затем `main` вливается в рабочую
  ветку. На GitHub (`intbio/ResParTools`) - только с явного согласия.
