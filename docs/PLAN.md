## Решения (кратко)
- Старые ноутбуки не редактируются; несовместимые старые вызовы - предупреждение, не ошибка.
- Родительский остаток указывается явно; без молчаливых подмен (функция сообщает).
- RESP по умолчанию: ACE-X-NME, φ/ψ заморожены (`fix_backbone=True`, флаг отключает или
  задаёт свои пары), 2 × 3 конформации, HF/6-31G*, MSK, двухстадийный RESP, равные веса.
- Два окружения (`darwin_ec`, `darwin_resp`), ноутбук остаётся в `darwin_ec`.
- Git: рабочие изменения - коммитами в `main` после подтверждения; отправка на GitHub
  (`intbio/ResParTools`) - только с явного согласия.
