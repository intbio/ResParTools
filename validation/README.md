# Проверка корректности на референсных остатках

`tests/` и `validation/` проверяют разное:
- `tests/` - **регрессия**: результат библиотеки на эталонном наборе модификаций совпадает с файлами в
  git (их сделал тот же код). Ловит изменения, но не ошибки, заложенные с самого начала.
- `validation/` - **корректность**: результат библиотеки сравнивается с **независимым источником** -
  файлами базового поля amber14sb, ручными эталонами, опубликованными значениями.

```bash
conda activate darwin_resp
python -m pytest validation -q            # ~40 с
```

Известное расхождение помечено `xfail(strict=True)` с причиной: оно видно в выводе (`x`), и когда его
исправят, тест сообщит об этом - пометку нужно снять.

## Проверки

| Файл | Что проверяется | Эталон | Состояние (2026-10-22) |
|---|---|---|---|
| `test_standard_residue_names.py` | стандартные аминокислоты проходят путь шагов 1-4 (мономер в тримере Gly-X-Gly, перенумерация, имена) - имена и порядок атомов | `aminoacids.rtp` amber14sb | 15 из 18 совпадают; Thr, Ile - правило имён, Trp - отложено |

## Планируется
- Типы атомов и hdb стандартных остатков через `assign_types` и `hdb_entries` - против
  `aminoacids.rtp` / `aminoacids.hdb`.
- Подгонка RESP на маленькой молекуле с известным ответом.
- Ручные эталоны имён атомов для модификаций (Formyl, Malonyl).
- Фосфосерин (`PSER` из [intbio/gromacs_ff](https://github.com/intbio/gromacs_ff),
  `amber14sb_parmbsc1_cufix_PTM.ff`) - сравнение с результатом библиотеки.
